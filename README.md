# Toast-mini-AI
A C++ chatbot
A mini C++ AI chatbot with:

- Token-based NLP
- Semantic memory (cosine similarity)
- Self-learning system
- Persistent memory (file-based)

## Features

- Learns from user input
- Remembers after restart
- Fuzzy intent matching
- Lightweight C++ engine
- You can teach it something
- Lightweight to can be run on old computer
## Build

```bash
g++ main.cpp ml.cpp utils.cpp banner.cpp -o toast
